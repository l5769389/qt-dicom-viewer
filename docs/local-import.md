# 本地文件与压缩导入（0.4.0）

将一个或多个 DICOM 文件、文件夹、压缩包拖入 Voxenra 窗口即可导入，也支持直接拖到 CT、PET 或融合的原生 3D 画面。首页「打开文件或压缩包…」和 Cmd/Ctrl+O 支持多选文件；原文件夹入口继续递归扫描。本地数据源关闭时这些入口禁用。

解压和扫描在后台执行，顶部显示状态，可取消导入。已有视图可以继续使用；本次完成或取消前不接收第二批文件。重复导入按序列 UID、实例 UID 合并，同一序列后续补入的切片追加到原序列。无后缀 DICOM 也按内容识别。损坏或非 DICOM 文件会跳过；无法解压、没有可用影像时显示提示，可关闭后重新导入。

## 支持范围

| 类型 | 格式 |
| --- | --- |
| 压缩包 | ZIP、7z、TAR、TAR.GZ / TGZ、TAR.BZ2 / TBZ2、TAR.XZ / TXZ |
| 单文件压缩 | GZ、BZ2、XZ |
| DICOM 像素编码 | JPEG Baseline、Extended、Lossless，JPEG-LS，JPEG 2000 / HTJ2K，RLE |
| 数据集压缩 | Deflated Explicit VR Little Endian |

当前不支持 RAR、加密包与分卷包。请先解密、解压，或转换为 ZIP / 7z。解码器恢复编码所能表达的像素，有损压缩造成的精度损失不会被恢复。支持的编码依据 [pydicom 插件表](https://pydicom.github.io/pydicom/stable/guides/plugin_table.html)，应用随包提供 pylibjpeg、libjpeg、OpenJPEG、RLE 与 JPEG-LS 解码依赖。

压缩支持不改变视图的数据要求：普通 2D / MPR 仍面向单帧灰度切片；彩色或多帧对象可扫描、预览缩略图及原始序列导出，本次不增加其完整阅片或体重建支持。

## 文件与缓存

- 拖入始终使用复制语义，不移动、覆盖或改写源文件。解压输出进入独立的当前会话临时目录。
- 从列表移除或清空序列不会删除缓存，已打开视图与导出仍可使用；再次导入部分切片不会截短已有完整序列。
- 正常退出时先取消 / 等待加载、渲染和导出任务，再清理解压缓存。
- 解压期间取消或失败，会删除本次产生的半成品；扫描期间取消，保留已载入项及其缓存。
- 单次最多 100000 个文件；归档中单文件不超过 8 GiB，累计解压不超过 32 GiB，嵌套最多 3 层。拒绝路径越界、软硬链接、设备文件、重复冲突文件名。超限数据可手动解压后分批导入。

## 窗值精度

WW / WL 输入框显示最多一位小数，整数不显示 `.0`。回车、点击应用和保存模板都使用相同精度，例如 `167.23147 / 56.995304` 提交为 `167.2 / 57`。输入期间不改变影像；原有固定输入框大小保持不变。
