# PET MPR 与 PET/CT 融合

## 使用

- 选择经典静态/全身 PT 序列，点击 MPR：轴位、冠状位、矢状位与全体积冠状 MIP 四宫格。
- Cmd/Ctrl + 单击选中一个 CT 和一个 PT，再点击「融合」或右键「融合浏览」。选择顺序不影响固定/移动层。
- 只选一个 CT 或 PT 时，「融合」打开配对对话框。同患者同检查优先；跨检查、患者不同或身份缺失需人工核对确认。
- 融合四格为 CT、PET、融合、PET MIP。前三格共用物理切面与画面变换；调窗面板内可切换轴位/冠状位/矢状位。
- 点击 MIP 的有效像素，定位到该射线上最大值所在的物理位置。MIP 是投影值，不提供二维 ROI/距离测量。

## 显示与定量

PET 使用「0–当前显示上限」，不使用 CT 的 WL/WW 交互。控制上限可输入或点击快捷项；当前上限始终约束在最小值与控制上限之间。快捷项含自定义控制值。

同一标签页共享 PET 单位、两个上限和重置基线，不同标签页相互独立。切换单位时，上限及快捷项按首次成功加载时的参考比例一起换算；新图像完成前保留旧单位和图像。更新失败仍可查看上一帧，并显示错误提示。

体积逐切片应用 padding、Modality LUT/rescale 和 SUV 计算后再插值。BQML 保存源活度；仅当全部切片可靠时开放 SUVbw，否则整卷降级为 Bq/ml 或 kBq/ml。原生 GML 保留 SUV 类型，不伪造可逆的源活度域。如果切片间转换比例不同，像素仍使用各切片真实比例；显示上限的参考换算不保证所有位置亮度不变。

CT 使用独立 WL/WW 和 HU；PET 单独视图默认为灰阶，融合 PET 层为 Hot Iron、叠加比例 50%。PET 零值、无效值和覆盖范围之外不遮挡 CT。融合光标分别显示 CT/PET 值；矩形、椭圆 ROI 的两套统计来自最终浮点采样，不来自 RGB 图像。单位或配准变化后按 ROI 几何重新统计，隐藏切面的 ROI 回到该切面时重算。

## 手动配准

CT 固定，4×4 矩阵的方向始终是 `PET LPS → CT LPS`。采样使用逆映射，不按切片号或矩阵尺寸配对。空间参考依据 [DICOM Frame of Reference 模块](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.7.4.html)。

相同且非空 FrameOfReferenceUID 初始化为「DICOM 坐标对齐」；不同或缺失仅为坐标预览，需手动确认配准。没有重叠时可用「中心对齐」，也可继续调整。

在调窗面板中开启手动配准：PET/融合格左拖为面内平移，右拖绕当前切面法线旋转。数值输入支持 CT LPS 三轴平移（mm）与旋转（°），旋转顺序 `Rz·Ry·Rx`；枢轴在进入编辑时固定为物理十字线位置。Esc 退出编辑并保留变换；「重置配准」恢复初始恒等坐标变换。画面平移/缩放/旋转与配准矩阵分别保存。

保存/加载使用本地 JSON，不是 DICOM REG。版本 1 包含固定/移动 Series UID、FrameOfReferenceUID、两卷几何指纹、变换方向、矩阵和枢轴。序列或几何不匹配、非有限值、非刚性矩阵和损坏文件均拒绝加载。

## 支持边界与验收

要求至少两张经典单帧静态/全身 PET，以及有限、完整、一致的规则正交空间网格。拒绝重复层位、不等距、层间偏移和不一致的方向/矩阵/FrameOfReferenceUID。CT 与 PET 之间允许不同方向、尺寸、间距和覆盖范围。

不包含自动/非刚性配准、动态或门控 PET、Enhanced PET、PET 体绘制、DICOM REG 导入导出，也不新增压缩解码依赖。当前验证使用合成 DICOM 与实际 QML 事件，不替代真实设备数据验证或临床验证。

后台按视口/融合标签合并为一个执行中请求及一个最新待执行请求；旧成功与旧失败不会覆盖新意图。体积、浮点切面和 MIP 峰值位置有缓存；仅调强度、色表或叠加比例不重新采样。MIP 按整个体积深度逐平面累积，内存不随投影深度线性增长。

自动化验收包括定量域与逐切片比例、NaN/padding、不同网格刚性对齐、MIP 定位、双层 ROI、单位切换回滚、请求合并、配对与身份确认、JSON 校验，以及真实 QML 四宫格/按钮/输入/鼠标配准事件。运行：

```bash
PYTHONPATH=src QT_QPA_PLATFORM=offscreen uv run pytest -q
```
