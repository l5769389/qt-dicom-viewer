# 3D 去床板与自由裁剪

去床板是每个 3D viewport 的独立布尔状态，工具入口不改变当前 interaction、active tool 或面板。裁剪是单独的左键交互，选区建立后由面板命令执行。裁剪内部表示删除圈内，裁剪外部表示删除圈外，均贯穿当前视线方向的全部深度。

## 数据与状态

`VolumeViewportController` 保存人体保留遮罩、累积裁剪保留遮罩及未执行的屏幕选区。最终可见区域是两个启用遮罩的交集。遮罩不会修改 `DicomVolume.modality_pixels`。关闭去床板只移除人体遮罩；重置裁剪只移除累积裁剪遮罩；全局重置同时清除两项显示效果。

遮罩计算使用 `QThreadPool`，不在工作线程创建 QWidget、渲染器或 OpenGL 上下文。每项任务携带递增 token，重置、换载和销毁使旧 token 失效。计算错误保留当前显示，并在工具栏下显示错误原因。去床板结果缓存于当前 viewport，再次开关无需重新计算。

## 自由选区与空间定位

左键轨迹按逻辑像素采集并限制于视口范围；松开后以 1 像素容差简化轮廓，小于 9 平方像素的选区不执行。黄色闭合轮廓由 VTK 2D actor 绘制，使用归一化视口坐标，在原生 WindowContainer 中可见且支持高 DPI。

选区记录当时的相机姿态及视口尺寸。每层体素经 voxel-to-patient 仿射、相机横纵基向量、平移及平行投影缩放映射回逻辑屏幕像素。凹多边形用奇偶填充规则判定并包含边界；内裁剪取补集，外裁剪取交集。按层计算，避免分配整卷浮点坐标网格。再次裁剪与上一遮罩求交，已移除的体素不会因另一角度的裁剪而恢复。

未执行选区在改变相机、视口大小、隐藏视图、切换交互或 Esc 时取消。点击 QML 裁剪按钮引起的焦点转移保留已经完成的选区；中途失焦的轨迹则取消。

## 去床板范围

仅对 CT 启用。选择最接近患者头脚方向的数据轴逐层处理，支持倒序与轴置换。先以 -500 HU 阈值提取组织并填充封闭孔洞，再用约 5 mm 半径的矩形腐蚀分离薄支撑物及窄接触，按连通区域的物理面积和长宽比筛选人体核心，膨胀恢复轮廓并填孔。保留多个足够大的区域以支持分离的双腿、手臂。扫描端部没有有效核心的层使用最近有效轮廓。

这是显示用的启发式轮廓估计。它不提供精确解剖分割，宽接触、厚床垫、极端倾斜、扫描边缘的小结构或非人体模体可能表现不佳；关闭开关即可恢复。没有可识别的人体区域时返回错误并保持未启用，不输出全空遮罩。

## 渲染与验证

使用 VTK GPU volume mapper 的二值遮罩（0 删除、255 保留），继承原体数据的尺寸、间距、原点和方向。遮罩不通过替换 HU 值实现，因此切换窗值、Composite、MIP、Additive 模式时删除区域不会重新显现。体数据及遮罩只在变化时上传，交互和静止均保持固定采样设置。

`tests/test_volume_edit.py` 验证 CT 模拟床板、窄接触、肺内空气、分离双腿、轴置换、凹选区、边界、斜位各向异性体数据的 VTK 投影一致性、状态组合与过期结果。`tests/test_volume_panel_qml.py` 验证实际按钮、禁用状态和底部重置。`scripts/smoke_3d.py` 在真实桌面/OpenGL 下验证自由轨迹、可见轮廓、内外裁剪，以及全空遮罩在六种模板下均不显示影像。
