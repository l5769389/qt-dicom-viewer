# Voxenra v1.0.1

本次更新聚焦阅片交互、导入结果与界面一致性。

## 主要更新

- **平铺阅片修复**：修复首张切片持续加载的问题；双击单张切片进入对应的 2D 视图并定位到该层。
- **鼠标与图标统一**：修复平铺等视图中系统指针与自定义指针重复显示、跨切片拖动时图标重复的问题；更新 MPR 十字线旋转和 3D 裁剪图标，裁剪指针与工具图标一致。优化按钮悬停和按下反馈。
- **弹窗操作整理**：应用内弹窗统一右上角关闭、固定底部取消与确认位置；主要操作、次要操作和删除采用不同颜色。优化 DICOM Tag 详情的尺寸、文字选择与复制。
- **导入结果重做**：保留系统原生标题栏，去掉重复关闭按钮和内容区内框；调整状态、进度与结果布局，长错误可滚动和复制，底部保留关闭、取消导入及失败重试。导入进行中防止意外关闭进度窗口。
- **资源与代码清理**：移除已被 SVG 替代的 21 个旧 PNG 图标、未使用组件、旧导入入口及过渡代码，清理约 9.8 MiB 的历史图标资源。

- **页签稳定性**：修复关闭 3D 页签后重新打开时可能出现的控制器生命周期崩溃。

## 下载

- **macOS · Apple Silicon**：`Voxenra-1.0.1-macos-arm64.dmg`，由本机打包。
- **Windows · x64**：`Voxenra-1.0.1-windows-x64-setup.exe`（安装版）与 `Voxenra-1.0.1-windows-x64-portable.exe`（便携版），由 GitHub Actions 构建。
- 各安装包附带 SHA-256 校验文件；安装包均对应 `v1.0.1` 标签源码。
