# Voxenra v1.0.0

本次正式版汇总了自 v0.2.0 以来的导入、阅片、PET 重建与界面改进。

## 主要更新

- **统一影像导入**：一个窗口混选 DICOM 文件、文件夹和压缩包，支持多选、路径定位与拖拽到应用或原生 3D 画面。新增 ZIP、RAR4 / RAR5（含固实压缩）、7z、TAR 及 GZ / BZ2 / XZ 等归档导入，后台解压扫描可取消，无需安装 WinRAR。PACS 继续支持 DICOMweb 查询、多序列下载与多连接配置。
- **独立 PET MPR 与 PET 3D**：无需 CT 配对即可打开 PET 三视图或三维体绘制。提供实际可用的定量单位、显示范围、色表、阈值和透明度；PET 3D 支持裁剪、恢复与 PNG 导出。完善 PET/CT 融合、手动配准及独立融合 3D 工作流。
- **阅片与显示工具**：CT 调窗增加数值输入、自定义模板保存与删除，窗值最多保留一位小数；MPR / 4D 同页签同步窗值与反白。新增首末页、前后 10 页与 1× / 2× / 5× / 10× 缩放快捷操作。平铺支持伪彩、CT 反白及序列详情折叠。
- **测量、标注与分析**：区分绘制 / 编辑、选中已完成状态，优化线段抗锯齿；长度、角度、ROI、箭头和文字箭头支持 Ctrl+C / Ctrl+V（macOS 为 ⌘+C / ⌘+V）复制粘贴。两类箭头可调整线宽、大小与颜色。水模 QA 的操作步骤与指标说明集中到离线手册。
- **序列管理与工作区**：序列列表独立滚动、稳定更新缩略图；支持批量移除和清空列表，保留源文件与已打开视图。收起侧栏后仍可通过缩略图使用右键菜单，并保留 PACS、手册与设置入口。工具栏宽度可拖动并保存，视图打开提供加载、取消和失败重试。
- **导出与界面完善**：序列及视口导出默认开启匿名，明确区分源序列 PNG 与当前画面截图。统一工具顺序、指针与操作图标，优化顶部栏、原生窗口按钮、小视图文字、比例尺和三维界面；README 补充完整功能与导入方式说明。

## 本次重新打包

- **导入稳定性**：大批量扫描改为后台整理、限频更新，进度窗口显示枚举、解压和读取状态，提供取消、失败重试及明确的数量上限提示。窗口尺寸固定，长提示内部换行、滚动，底部按钮保持原位。
- **更小的安装包**：移除未使用的 Qt 模块与旧图标原稿，保留 CT / PET 三维绘制和压缩包导入功能。macOS 使用 LZMA DMG，Windows 安装器提高整体压缩率。
- **Windows 安装目录**：默认使用 `%LOCALAPPDATA%\Programs\Voxenra`，不再自动沿用旧品牌目录；升级时刷新安装器管理的 Qt 运行库，减少旧组件残留。用户影像、设置与日志保留。
- **界面细节**：右侧操作按钮横纵间距略微增大，改善按钮区的辨识与操作。

这是 v1.0.0 的重新构建，下载文件名和版本号不变，附件与 SHA-256 已更新；需要这些修复时请重新下载安装包。

## 下载

- **macOS · Apple Silicon**：`Voxenra-1.0.0-macos-arm64.dmg`，由本机打包。
- **Windows · x64**：`Voxenra-1.0.0-windows-x64-setup.exe`（安装版）和 `Voxenra-1.0.0-windows-x64-portable.exe`（便携版），由 GitHub Actions 构建。

压缩包导入当前不支持加密包或分卷包；归档支持不代表新增 DICOM 像素编码。匿名导出清理身份元数据和截图文字，不自动擦除影像像素内烧录的文字或人脸。
