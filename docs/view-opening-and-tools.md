## 独立 PET MPR

选择一个静态 PT 序列并打开 MPR，显示轴位、冠状位和矢状位，不需要 CT 配对。布局与 CT MPR 一致：左上轴位、左下矢状位、右侧冠状位。三个方向共用物理定位、PET 强度范围和定量单位；伪彩沿用全局 PET 设置。独立 PET MPR 不创建或计算第四个 MIP。PET/CT 融合仍保留 CT、PET、融合和 MIP 四格。

## 打开视图

- 创建页签后显示加载状态，主线程分批创建 QML 页面，DICOM 解码、体数据构建和重采样沿用后台渲染服务。
- 图像页签等待首轮所需视图：2D／3D 为首幅影像或体数据，MPR／4D 为三个方向，PET 工作区为整批结果，平铺为首次可用切片。Tag 等待首次标签读取；设置、PACS 和手册显示界面创建状态。
- 加载时覆盖尚未就绪的内容并禁用该页签影像工具，页签栏和左侧导航可操作；可以切换到其他页签，或通过「取消打开」关闭当前页签。后台返回的旧视口结果不会恢复已关闭页签，也不能完成重开页签的加载状态。
- 失败显示实际原因，支持「重试」或关闭。MPR 重试重新提交三方向；Tag 复用标签读取重试。
- 已打开页签保留控制器、图像、相机及测量状态。切换时异步重建对应界面，不重新解码已载入数据；普通翻页、调窗不触发全屏首次加载遮罩；独立 PET 3D 的单位切换涉及后台体数据转换，会复用加载、失败重试及关闭流程。
- 3D 原生窗口在体数据就绪后创建。VTK 原生窗口和 GPU 绘制仍遵守 GUI 线程约束；加载提示不代表任何硬件上的首次 GPU 绘制都无延迟。

## 验证

`tests/test_view_opening.py` 覆盖慢后台任务时 GUI 定时器和页签操作可用、三方向加载完成、部分失败重试、Tag 重试、关闭重开后的迟到结果、PET 三视图真实布局及公共按钮排序。PET 重建和融合原有回归继续覆盖定量单位、窗口、伪彩、定位和配准。

工具排序与首次加载阶段完整 pytest 为 914 项通过、15 项跳过；后续独立 PET 3D 和布局调整的最新结果见 `docs/validation/series-tools-polish.md`。
