# 影像工作区样式审核与优化

2026-09-07 · `codex/imaging-ui-polish` · 基于 `main@4093984`

本轮根据反馈修复测量设置的实际显示链路，改用 MPR 十字定位图标，减少设置分隔线，并合并 ROI 宽高设置与几何指标排版。截图使用合成测试影像。

## 本轮调整

| 区域 | 最终设计 |
|---|---|
| MPR | 突出 MPR 的共享定位点、四向十字线和影像边角；使用 Qt Quick 几何图形，24 / 28 / 48 px 均验证可见。 |
| 伪彩 | 左侧灰阶、右侧色带，中间箭头表达映射关系。普通伪彩和灰阶伪彩入口共用图形。 |
| 文件入口 | 改用冷蓝色 `#85c6ec` 和低亮度蓝灰背景 `#203847`；融合交叠区保留青绿色。 |
| 设置导航 | 156 px 单行分类导航，按连接、影像显示、测量分组；选中项使用细色条，八个分类在 1000 × 600 窗口内可见。 |
| 设置表单 | 参数区与预览区分开，预览最多 280 px；内容区不足 720 px 时上下排列。一级和二级标题通过字号与留白区分，移除重复的标题分隔线。 |
| 颜色与数值 | 默认显示色块和十六进制色值，点击色块展开色板；滑块旁可直接输入数值，无效输入离开焦点后恢复已有值。 |
| 测量与标注 | 测量线条、箭头两个参数组，右侧提供短线、端点、读数与箭头预览。 |
| 四角信息 | 选择一个角后编辑内容和顺序；提供四角布局预览及数量，已选字段从可添加列表中排除。保留每角最多 8 项。 |
| 窗模板 | 对齐名称、WW、WL 和操作列；新增与编辑表单同行排列，数值输入框限制为 100 px，页面最多 760 px。 |
| ROI 指标 | 宽度与高度由一个开关控制；尺寸与面积同行，字号增大时实际指标卡适当扩宽，窄视口可换行。 |
| 十字线、比例尺、ROI | 共用参数与预览布局；预览使用已有的实际显示组件，样式与工作区同步。 |

延续此前调整：两侧主工具栏只显示图标，操作名称通过悬停与键盘焦点提示显示；4D 与其他导航图标同色；设置入口为 36 × 36 px；基础控件为 32 px。标注长文本滚动、色块换行、QA 参数换行与 PET 内容区适配仍保留。

影像灰阶与伪彩映射、MPR 方位颜色、测量单位和计算逻辑未作修改。

## 测量设置修复

- 文字箭头先前固定线宽和箭头头部大小，现跟随全局线宽、虚线和头部大小设置。
- 箭头头部大小与文字字号分离；原先头部大小误用作文字字号。
- 改变全局标注颜色或文字字号，会更新所有已有标注；修改无关的线宽等设置时，保留在右侧工具中单独编辑的颜色和字号。
- ROI 指标原先使用“设置字号减 2 px”，现使用设置的实际字号；角度圆弧和 MTF ROI 图层接入测量线宽与样式。
- 普通长度、角度、矩形和椭圆都验证了选中与取消选中后的颜色、虚线、线宽和文字变化。选中对象使用编辑样式，取消选中后使用完成样式，设置页提供对应说明。
- 旧 ROI 配置中的独立宽、高开关会迁移为一个 `dimensions` 开关；旧配置只要隐藏了其中一项，就保持整组隐藏。后续保存使用统一开关。
