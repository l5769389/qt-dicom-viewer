## 界面和交互

真实 QML 验证了重复标题/方向下拉和联动开关消失；顶部左侧排列三方向与融合 3D。前三格始终联动，ROI 的 CT/PET 浮点数据来自同一物理网格。3D 仍使用独立标签，重复点击返回已有标签。

CT/PET 两个一级工具拥有独立面板、选中状态和重置。真实鼠标事件逐格检查：CT 工具只改变 CT/融合格的 CT 窗；PET 工具只改变 PET/融合/MIP 的 PET 强度；不适用的格不改窗。各工具的重置不影响另一模态或伪彩、比例、配准。普通 CT/PET 单序列调窗回归保持通过。

视口设置中的「小十字 / 参考线」「精简 / 详细」采用互斥按钮；检查默认值、反复点击不取消唯一选项、悬停能力、边框和键盘焦点/空格操作。四格均更新实际 QML 十字样式，包括 MIP；信息详略也共享。精简/详细均隐藏融合 ID，各角超长文字换行、省略且不越过半视口边界。配准无实际编辑时不显示状态，编辑及已应用变换仅在配准面板中显示；低分辨率投影仍标识其显示质量，实际加载错误与无重叠提示保留。

定位测试覆盖 CT、PET、融合、MIP，以及调窗、平移、测量、文字标注和配准工具。鼠标按下时锁定命中，短臂抓取保留偏移和固定采样几何；未命中的按下不会被后续回图抢走。人为暂停执行中和后续后台任务，验证即时定位、同手势旧影像展示、最新目标不回退、一个执行中加一个最新待执行、最终释放、切换工具/切面、关闭标签和失败回滚。

缓存测试验证同切面定位不增加采样、投影、QImage 复制、imageSource 版本或 ROI 刷新；手势中体积只校验一次，释放重新校验两卷。真实切面改变 0.37 mm 时重新采样的像素与直接浮点采样一致，MIP 仍复用。模拟时钟验证连续提交间隔不小于 33 ms，释放立即提交最终位置。配准的 128×128 / 64 深度 MIP 预览、180 ms 输入细化和失败回退仍独立验证。

## 性能对比

使用同一脚本分别运行精简前源码快照与本次实现，原始输出见 [优化前 JSON](locator-before.json)、[优化后 JSON](locator-after.json)。环境为 macOS 26.6.2 ARM64，Python 3.13.14，实际 Qt Quick 窗口 1280×900。

CT 为 **457×512×512**、PET 为 **104×128×128** 的 float32 合成体积。为聚焦交互，已解码体积预置进 VolumeManager 缓存；仍用真实指纹逻辑检查 561 条实例元数据，文件来自生成的种子 DICOM。首次扫描/解码不计入基准。MIP 先完成全精度预热。使用 QTest 鼠标事件，以实际 QML 十字位置到达目标为反馈终点，不包含屏幕合成器/vsync 的物理呈现时间。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 同切面 30 次定位，反馈 P95 | 44.01 ms | **1.65 ms** |
| 后台每次延迟 120 ms，30 次定位反馈 P95 | 182.37 ms | **0.38 ms** |
| 每 8 ms 连续移动，100 次即时跟随 | 0 / 100 | **100 / 100** |
| 连续移动且后台延迟时，即时反馈 P95 | 无即时反馈样本 | **2.54 ms** |
| 同切面 30 次定位，采样 / QImage 复制 / imageSource 更新 | 60 / 124 / 124 | **0 / 0 / 0** |
| 同切面 30 次定位，ROI 刷新 | 93 | **0** |
| 连续 100 次移动，提交 / 执行批次 | 101 / 6 | **27 / 9** |
| 连续 100 次移动，采样 / MIP 投影 / QImage 复制 | 12 / 0 / 4 | **0 / 0 / 0** |
| 连续 100 次移动，体积校验 | 12 | **4**（开始与释放各两卷） |
| 12 次真实切面变化，CT/PET 采样数 | 24 | **24** |
| 12 次真实切面变化，QImage 复制 / ROI 刷新 | 48 / 36 | **36 / 24**（跳过 MIP） |
| 真实切面变化影像更新 P50 / P95 | 39.83 / 44.21 ms | **39.68 / 54.61 ms** |

30 次定位组在每次十字到位后发送下一事件；优化后到位更快，因此请求合并更多。连续组固定约 8 ms 发送间隔，适合比较持续输入：优化后执行批次略多，是因为缓存批次更快且已完成影像不再被全部丢弃，实际采样/上传工作仍为零。

后端影像更新和定位反馈分别计量：正常同切面批次从请求到可展示的 P95 为 13.03 ms；持续输入并注入 120 ms 后台延迟时为 219.09 ms，十字反馈仍为 2.54 ms。真正切面改变需要完整采样，影像更新 P95 本次测量未改善，不能把定位延迟的下降解读为所有重建都低于 33 ms。同切面 MIP 投影优化前已有缓存；本次额外消除了重复着色、复制与纹理源刷新。imageSource 版本保持不变用来验证没有因定位重新请求纹理，并非硬件 GPU 性能计数器。

复现：

```sh
PYTHONPATH=src python scripts/benchmark_pet_locator.py /tmp/pet-locator-after.json
# 优化前比较需指向改动前 qt_dicom_viewer 包的父目录
PYTHONPATH=/path/to/before python scripts/benchmark_pet_locator.py /tmp/pet-locator-before.json
```
