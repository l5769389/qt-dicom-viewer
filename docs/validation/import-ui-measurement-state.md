# 混合文件选择与测量／标注剪贴板验证

在现有 0.4.0 worktree 上继续修改，保留此前测量的“松开后选中已完成、点击后选中草稿”区分。

## 最终行为

- 首页、展开／收起侧栏和 Cmd/Ctrl+O 均直接打开同一个混合选择窗口。文件夹、文件、压缩包可以一次共同选中并导入，不再经过类型菜单。
- 选择窗口支持 Ctrl / ⌘ 多选、双击进入文件夹、当前文件夹导入、路径输入定位、上一级和计算机目录。使用异步 QFileSystemModel，中文列标题，应用内统一深色外观。
- 移除顶部与侧栏的导入提示条及消失计时器；导入期间再次点击原入口可取消。源文件、缓存管理、RAR 与已有视图行为保留。
- 有焦点的影像视口支持 Ctrl+C / Ctrl+V（macOS 为 ⌘+C / ⌘+V）。长度、角度、矩形／椭圆 ROI、箭头和文字箭头均可复制，粘贴产生独立 ID，自动选中为已完成。
- 副本使用图像像素坐标，每次偏移 10 像素；目标切片的长度、角度及 ROI 统计重新计算，不复制旧统计值。文字箭头保留文字、颜色和字号。输入框保持普通文字复制粘贴。
- 剪贴板采用有版本的有限 JSON 格式，只保存类型、几何及文字样式，不携带患者标识或原图。损坏、异常大数值、未知类型及超限内容均忽略；未完成绘制或等待新切片时不粘贴。

## 验证

环境：macOS Apple Silicon，Python 3.13.14、PySide6 6.11.1，锁文件对应的独立环境。

- 混合选择与复制粘贴专项：24 passed。真实鼠标混合选中文件夹／DICOM／RAR、一次扫描三种来源、目录导航与取消、四个入口直接打开；真实键盘复制六类对象、重复粘贴、删除副本、跨视口目标间距计算、等待切片拒绝粘贴、异常剪贴板、文本编辑焦点隔离。截图检查通过。
- 完整 pytest 按文件隔离进程执行 84 个测试文件：1158 passed、22 skipped、0 failed。无新增 QML 布局或绑定警告。既有长时间单进程 Qt 生命周期问题参见 [历史记录](compressed-import.md)，本次未声称修复。
- macOS 原生 CT、PET、融合 3D 各 1 passed：RAR 拖入后，从展开与折叠侧栏打开真实混合选择窗口并取消，原 3D 视图继续可用。
- Windows 原生选择窗口与剪贴板交互仍需 Windows 主机验收。
- Python F 类检查及 git diff --check 通过。

相关用例：tests/test_import_ui.py、tests/test_annotation_clipboard.py、tests/test_local_import.py、tests/test_measurement_controller.py 和 tests/test_measurement_finish_style.py。导入说明与应用操作手册已同步更新。
